Lexibulles — Assistance

Une question, un bug, une idée de thème ? Écrivez-nous : thomas@littleprecious.fr. Indiquez si possible le modèle de votre téléphone et le numéro du niveau.

Questions fréquentes

Comment jouer ?

Faites glisser une bulle sur une autre : si les deux mots appartiennent au même thème, elles fusionnent. Réunissez tous les mots d'un thème pour faire éclater le groupe, et retrouvez tous les thèmes avant d'avoir épuisé vos coups. Les règles complètes sont dans le menu du jeu.

Les bulles sont bloquées, que faire ?

Secouez votre téléphone pour les mélanger. Sur iPhone, autorisez l'accès aux mouvements si le téléphone vous le demande.

Vais-je perdre ma progression ?

Votre progression est gardée sur votre téléphone, même si vous quittez le jeu. Elle est effacée si vous désinstallez l'application.

Le jeu contient-il des publicités ou des achats ?

Non. Les pièces se gagnent en jouant.
